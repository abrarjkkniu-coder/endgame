# Md. Abrar Hasan - Personal Portfolio 🕸️

A highly interactive, cinematic, and comic-book-inspired personal portfolio designed for the web. Built with a unique "Spider-Verse" aesthetic, this single-page application highlights leadership, creative works, and professional journey through engaging animations and storytelling.

## 🚀 Features

*   **Cinematic Intro:** A full-screen animated GIF backdrop with typewriter-effect dialogue ("Ok, let's do this one last time...") and synchronized background audio.
*   **Comic-Book Aesthetic:** Authentic "Ben-Day" dots background, bold typography (`Bangers` font), comic-style pop-ups ("THWIP!", "BAM!"), and jagged dialogue boxes.
*   **Interactive Canvas:** A custom vanilla JavaScript particle canvas where nodes connect to your cursor, mimicking a spider's web.
*   **Interactive Journey Timeline:** A draggable, touch-friendly slider documenting professional milestones with smooth 3D tilt effects on the cards.
*   **"Spider-Sense" Cursor:** A custom tracking reticle replaces the standard mouse cursor.
*   **Audio Player Widget:** A floating, spinning music widget with built-in playback controls.
*   **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices with a touch-friendly bottom dock navigation for smaller screens.
*   **Color Suits (Themes):** Toggle between "Classic" (Navy/Red) and "Midnight" (Dark/Neon) color palettes.

## 🛠️ Technologies Used

*   **HTML5:** Semantic structure and single-file architecture.
*   **CSS3:** Advanced animations (`@keyframes`), custom properties (CSS variables), CSS Grid/Flexbox, 3D transforms, and media queries.
*   **JavaScript (ES6+):** DOM manipulation, interactive canvas rendering, intersection observers for scroll animations, and audio control. No external JS libraries were used.

## 🏃‍♂️ How to Run Locally

Because this project is built entirely with vanilla web technologies and consolidated into a single file, running it is incredibly simple:

1. Clone or download this repository.
2. Double-click `index.html` to open it in your default web browser.
3. *Note: For the best experience, ensure you have an active internet connection so the external fonts, images, and audio track can load properly.*

## 📂 Project Structure

This project uses a strict single-file architecture for the core application to ensure maximum portability. All HTML, CSS, and JavaScript are contained within `index.html`.
